# Barangay Outreach Tracker

Double-click **Start Tracker.bat**, then open <http://127.0.0.1:8765>.
Keep the server window open while using the tracker. Python 3.12 is installed on the project laptop.

**Dashboard** shows **Scheduled meetings**, **Completed meetings** (meeting rows, including follow-ups), **Completed barangays** (each barangay with at least one completed meeting counted once), and **Barangays with no movement** (no saved meeting row, including Not set), matching the Barangay status **Has movement: No** filter exactly. Email/text flags and manual meeting overrides do not affect this count. The outreach chart remains available below these cards. The meeting-status pie counts each roster barangay once, prioritizing Complete, then Scheduled, then Not set; it can correctly differ from meeting-row totals. For example, two completed Atok Trail meetings count as two meetings and one completed barangay.

The visible Dashboard reloads saved CSV state on entry and every 10 seconds, with a Last checked time. It resumes checking when the page becomes visible. Refresh errors retain the last loaded data and show a retry notice. Polling pauses outside Dashboard, in hidden pages and while an editor is open; a pending refresh cannot replace a newer save. Refresh the tracker page after updating the app.

- **Meetings** lets you add a meeting, change its date or time, or mark it complete. Add follow-ups as separate meetings.
- To combine duplicate meetings, right-click the row you want to remove and choose **Merge meeting**. Pick another row for the same barangay with the same status, or merge a **Not set** row into a **Scheduled** row. Confirming keeps the selected meeting's date, time, and status and combines the remarks. Restart the tracker server and refresh after updating.
- In **Meetings**, choose **Export as → Text JSON**, filter and select rows, then click **Confirm**. Choose **Personalized messages** to edit the prefilled message for each mobile number, or choose **One common message for all** to write a shared message. Click **Download JSON** to export in the existing iPhone Shortcuts format with one entry per normalized official Punong Barangay mobile number. Rows without a valid mobile are marked. Exporting leaves the tracker CSVs and outreach flags as they were.
- In **Meetings**, click **Email draft**. Filter by status or date, then check individual rows or click **Select all shown**. To draft for a specific date across statuses, choose **All meetings** and enter the date. Changing filters clears your selection. Click **Confirm** to copy the deduplicated BCC list and edit the message. Same-date Scheduled selections get the meeting reminder. Other selections start with a greeting and signature. Rows without an email address are marked in the list. Drafting does not update outreach flags or send email.
- Click a meeting row (or focus it and press Enter/Space) to open its barangay in **Barangay status**, with the name searched and matching row highlighted. Edit and status buttons keep their existing actions. Clear the search to see the full roster again.
- **Barangay status** lets you record whether an email was sent or a text reply was received. Search by barangay, email, or Punong Barangay.
- **Barangay status** also offers **Email draft** and **Export as → Text JSON**. Apply its search/status filters, select rows or **Select all shown**, then **Confirm**. The shared editors use general outreach wording without inferred meeting dates. Email uses the barangay email address; text uses the official Punong Barangay mobile, with duplicate recipients combined. Missing contacts are marked. Personalized/common text modes and the iPhone JSON format are the same as Meetings. Changing filters or tabs clears the selection. Drafting and exporting do not send messages or update outreach flags. Refresh the tracker page after updating.
- In **Review barangay texts → Personalized messages**, edit the **Personalized message template** and click **Apply template to all**. Every `<Barangay>` is replaced with that recipient's selected barangay name(s). The default asks when the official is available for an online meeting to confirm collection sites/staging areas. Review or edit each message before downloading. Applying again replaces individual edits; merely typing in the template leaves them intact. Blank templates are rejected. Template edits last while the dialog is open and reset on reopening. **One common message for all** remains a literal shared message without placeholder substitution.
- Right-click the **Email address**, **Barangay phone**, **Punong Barangay**, or **Punong Barangay phone** cell and choose **Edit** to change that field. You can also focus the cell and press **Shift+F10**. Restart the local tracker server to pick up the contact-save endpoint.
- In **Barangay status**, **Has movement** displays **Yes** when the barangay has any saved row in **Meetings**, including **Not set**, and **No** when there are no saved rows. Use **Has movement: Yes** or **Has movement: No** to filter the roster. The value is read-only and comes from the meeting log.
- Click **Has meeting**, **Emailed**, **Texted**, or **Replied by text** to flip the flag directly in the row. Blank outreach values display as **Not recorded** until set. **Has meeting** follows the meeting log until you set a manual override.

Both CSVs live in the ignored **data/** folder. Back up both files together. Close them in Excel before saving from the tracker. The roster contains two rows with a missing or numeric barangay name. They are flagged for review in the roster and omitted from the meeting picker.

Choose **Export as → Export all** to copy both complete working files to a new Manila-time folder under **output/**, regardless of active tab or filters. These snapshots are ignored by Git because they contain contact and outreach data.

In **Meetings** or **Barangay status**, choose **Export as → CSV for Sheets**. Apply the current tab's filters, check individual rows or **Select all shown**, then **Confirm** to download a CSV. Missing email/mobile values do not prevent CSV selection. Meetings exports Barangay, Meeting date, Day, Time, Status and Remark; Barangay status exports Barangay, Email address, Barangay phone, Punong Barangay and Punong Barangay phone. Values are preserved, including blank fields and original time text. Import the file through Google Sheets' File → Import; to preserve phone numbers exactly, disable automatic conversion of text to numbers, dates and formulas. These selected CSVs are for reporting, not tracker backup/import. Dashboard offers only Export all. The old standalone text-export button has been removed; Email draft stays separate.

Click **Import CSV** to load one or both files from a current tracker export, including renamed exports. Confirming replaces the selected tables. The tracker validates the file columns and meeting references, then backs up the current pair under **output/** before applying the import.

On a fresh copy, run `python server.py --checklist "C:/path/to/Barangay Outreach Checklist.csv"` on first launch to seed past meetings and emails. Later launches keep the saved CSVs. The contact roster comes from the repository source CSV.

Run `python check_tracker.py` to verify persistence and separate follow-up rows.
Run `node --test email-draft.test.mjs` to verify draft content and recipient deduplication.
